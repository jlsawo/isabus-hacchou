# いさバス — スマホ用 バス接近表示

八丁・法務局杉並出張所・清水二丁目から **荻窪駅・阿佐ヶ谷駅方面** へ向かう便を、来る順に7件表示する Web アプリです。
以前は「いさバス八丁」という名前でした（旧いさバス [jlsawo/busboard](https://github.com/jlsawo/busboard) の後継）。URL は https://jlsawo.github.io/isabus-hacchou/ のままです。
Android の Chrome で開いて「ホーム画面に追加」→「インストール」すると、アプリとして使えます。

分数の色は、八丁が薄めの緑、法務局杉並出張所が桜色、清水二丁目が青です（`config.js` の `stops[].color`）。

画面上のボタンで **「荻窪駅から」** 表示に切り替えられます。荻窪駅ののりばから乗って法務局杉並出張所・清水二丁目で降りる便を、
荻窪駅を出る時刻の順に表示します（乗り場・降りる停留所・着く見込み時刻つき）。
各行の **📍**（控えめな灰色）を押すと、吹き出しで乗り場の場所を見られます（× で閉じる）。
地図は道路（ロータリー・青梅街道）と線路だけのシンプルな絵で、荻窪駅のすべてののりばを灰色の点で描き、その便の乗り場だけを赤く示します。
駅は四角で描き（`config.js` の `returnMode.landmark`）、右上にコンパス（北が上）を置きます。文字は「青梅街道」と「荻窪駅」だけです。道路と線路の形は OpenStreetMap（© OpenStreetMap contributors）から
GitHub Actions（`.github/workflows/roads.yml` → `tools/fetch_roads.py`）で取得して `roads.json` に同梱しているので、📍 を押すとすぐ描けます
（毎月1日に自動で取り直し。`roads.json` が無いときだけ、その場で Overpass API から取得）。のりばの位置は時刻表データの stops.txt を使います。
範囲はどの乗り場でも同じで、印の位置だけが変わります。
降りるのりばは `config.js` の `returnMode.stops` で決めます。

「荻窪駅行き」は、ふだんは八丁を除いて表示し、画面上部の **「八丁あり」** を押すと八丁の便を加えます（もう一度押すと戻ります。選んだ状態は次回も保持）。
加えるのりばは `config.js` の `optional` で決めます。
Chrome で開いていてまだインストールしていないときは、画面上部に **「ホーム画面に追加」** ボタンが出ます。

## 仕組み

- **時刻表**（GTFS 静的データ）: スマホが [ODPT](https://developer.odpt.org/) から zip をダウンロードし、端末内で対象のりばの便だけを抜き出して保存します。7日たつと起動時に裏で自動的に取り直します。運行日の期限が切れたデータは、最後のダイヤを延長して使います（祝日は日曜ダイヤ）。
- **リアルタイム情報**（GTFS-RT TripUpdate）: 表示中は1分ごとに取得し、遅れ・欠航を反映します。
- **アクセストークン**: 設定画面で入力し、端末の localStorage にだけ保存します。このリポジトリにはトークンもバスのデータも含まれません。
- **のりばを調べる**: 設定画面で停留所名を検索すると、のりばごとの stop_id・系統・行先・便数が出ます。目的の方面の stop_id を `config.js` に書きます。

## ライセンス・利用条件のメモ

ODPT の「公共交通オープンデータ基本ライセンス」に基づいて利用します。
取得したデータは各自のスマホの中だけで使い、第三者が再利用できる形で公開・再配布しません（第8条4項(1)）。
画面フッタに ODPT のデータ生成時刻・取得時刻・時刻表の取得日を表示しています（開発者ガイドライン 2.1.1 / 2.2.1）。
